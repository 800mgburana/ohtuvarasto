## Warehouse web app

Start the app from the project root:

```bash
python src/varasto_app.py
```

Open [http://127.0.0.1:8000](http://127.0.0.1:8000) in your browser. Create
warehouses, then add or remove stock using each warehouse's controls. Warehouses
and balances are saved to `varastot.json` in the current directory.
